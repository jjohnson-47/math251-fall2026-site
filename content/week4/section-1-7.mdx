# Limits, Continuity, and Differentiability (Section 1.7)

For three weeks you have computed derivatives and read what they mean. This
section asks the question sitting underneath all of it: **when does a derivative
exist at all?** The answer is more interesting than yes-or-no, and it turns on
the difference between a function being unbroken and a function being smooth.

<EmbedCard
  anchor="three-conditions"
  title="Continuity, in three separate conditions"
  tone="note"
>

A function $f$ is continuous at $x = a$ when all three of these hold:

1. $f(a)$ is defined. The function has a value there at all.
2. The limit of $f(x)$ as $x$ approaches $a$ exists. The function is heading
   somewhere from both sides, and to the same place.
3. Those two agree. Where the function is heading is where it actually is.

They are listed separately on purpose. When continuity fails, you should be able
to say **which one** failed, because each failure looks different on a graph and
means something different about the situation being modelled.

</EmbedCard>

<EmbedCard anchor="two-failures" title="Two ways it fails" tone="warn">

**A removable discontinuity** breaks condition 3. The limit exists and the
function value is simply in the wrong place, or missing. There is a hole, and
one repaired value fixes it.

**A jump discontinuity** breaks condition 2. The one-sided limits both exist and
disagree, so there is no single limit. No repair fixes this one; the function
genuinely goes to two different places depending on which side you arrive from.

</EmbedCard>

<EmbedCard
  anchor="differentiable-is-stronger"
  title="Differentiable is stronger than continuous"
  tone="note"
>

**If $f$ is differentiable at $a$, then $f$ is continuous at $a$.** That
direction always holds: a function with a well-defined slope at a point cannot
be broken there.

**The converse is false, and that is the point of this section.** Continuity
buys you an unbroken graph. It does not buy you a slope.

The example to keep in your head is $g(x) = |x - 2|$ at $x = 2$. Nothing is
broken and nothing jumps, so it is continuous. But approach the corner from the
left and the slope is $-1$; approach from the right and it is $+1$. The
difference quotients disagree, so there is no single derivative. A corner is
continuous and not differentiable.

</EmbedCard>

<EmbedCard anchor="predict" title="Predict, then check" tone="quiet">

Answer each one in your head first, then open it.

<PredictReveal question="A graph has a hole at one point that a single repaired value would fill. Which of the three conditions failed?">

Condition 3, and only condition 3. The limit exists, so condition 2 holds, and
the function value is either missing or sitting somewhere else. Where the
function is heading and where it actually is have come apart. That is a
removable discontinuity, and one repaired value fixes it.

</PredictReveal>

<PredictReveal question="Is a function that is continuous at a point automatically differentiable there?">

No, and that is the whole point of the section. Continuity buys an unbroken
graph and nothing more. The function $g(x) = |x - 2|$ is continuous at $x = 2$,
but the difference quotients give $-1$ from the left and $+1$ from the right, so
there is no single number for the slope to be.

</PredictReveal>

<PredictReveal question="A function is differentiable at x = 4. Can it be discontinuous there?">

No. Differentiability at a point forces continuity at that point, so a function
with a well-defined slope at $x = 4$ cannot be broken at $x = 4$. The
implication runs in that direction only, and the converse fails at every corner.

</PredictReveal>
