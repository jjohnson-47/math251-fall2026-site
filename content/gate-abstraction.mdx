        className="mt-3 font-heading text-4xl leading-[0.98] font-semibold tracking-[-0.035em] text-balance sm:text-5xl"
      >
        These measurements already contain the derivative.
      </h2>

      Call the time $t$ and the position $s(t)$ — the same letter *Active
      Calculus* uses for a position function. Gate A is crossed at time $t$ and
      gate B at $t+h$, so

      $$
      \Delta s=s(t+h)-s(t),\qquad \Delta t=h,
      $$

      and the readout is

      $$
      \frac{\Delta s}{\Delta t}=\frac{s(t+h)-s(t)}{h}.
      $$

      Squeezing the gates is making $h$ small. At the 25-metre mark, the
      averages approach $10\ \text{m/s}$ even though the two gates never occupy
      the same place:

      $$
      s'(t)=\lim_{h\to 0}\frac{s(t+h)-s(t)}{h}.
      $$

      A position function is one example of a function, so from Section 1.3 the
      book writes the same limit for any $f$:

      $$
      f'(a)=\lim_{h\to 0}\frac{f(a+h)-f(a)}{h}.
      $$

      Nothing changes but the letter. When the moving object is gone, $s$ becomes
      $f$ and the derivative is whatever that function's rate of change happens
      to measure.

      <p className="math-caption">
        The notation describes the same measurement process in mathematical
        terms. Here, the limit is the value approached as the distance between
        the gates tends to zero.
      </p>

      <p className="math-caption">
        <em>Active Calculus</em> §1.1 writes this without the Δ, as
        $\mathrm{AV}_{[a,b]}=\frac{s(b)-s(a)}{b-a}$. It is the same subtraction
        over the same subtraction. Δ is only a name for the difference.
      </p>
